# Codex와 Claude 교차 검증

이 폴더에서는 Codex가 수정한 코드와 재현 결과를 같은 범위에서 Claude가 독립적으로 검토합니다. 검토 자료와 응답은 `reviews/<작업>/`에 저장합니다.

1. Codex가 검토 요청 `REQUEST.md`, 기준 커밋과 변경분 `changes.patch`, 실행 결과 `verification.txt`를 준비합니다.
2. Claude가 해당 자료를 읽고 재현 조건, 수정의 타당성, 누락된 회귀 테스트를 검토합니다. 확인한 사항과 추정은 구분하고 파일과 줄을 함께 기록합니다. 응답은 `CLAUDE-REVIEW.md`에 저장합니다.
3. Codex가 지적 사항을 코드와 브라우저에서 다시 확인하고, 반영 여부와 근거를 `RESOLUTION.md`에 기록합니다.

검토 자료에는 작업에 필요한 파일만 담습니다. Claude에 전달할 변경분과 로그는 공유 전에 비밀값이나 사용자 데이터가 들어 있지 않은지 확인합니다.

## 헤더 검증

로컬 서버와 Chrome이 실행 가능한 환경에서 저장소 루트의 `node orchestra/check-header.cjs`를 실행합니다. 검증은 회사 사이트와 상품몰의 언어 메뉴, 네 가지 언어 전환, 회사의 사업 영역·모바일 메뉴·로그인 창, 상품몰의 카테고리와 대량 담기 시트를 확인합니다. 외부 번역 API 응답은 테스트 데이터로 대체합니다.

포트나 브라우저 경로가 다르면 각각 `ORCHESTRA_BASE_URL`과 `ORCHESTRA_BROWSER_PATH`로 지정할 수 있습니다.
